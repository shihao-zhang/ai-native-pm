# 按需使用的任务与交接模板

这两份模板帮助写清执行边界和接续上下文，可以直接复制填写，也可将相关字段放进已有工单或状态记录。它们不增加必经交付物，不要求每个需求建立多个会话，也不要求每次小改重新走一套流程。

| 当前需要 | 使用哪份 | 帮助交代什么 |
|---|---|---|
| 把已定任务交给执行方，或分批修改同一产物 | [执行指令模板](执行指令模板.md) | 本批目标、有效输入、差异、已定约束与留白、写区、产物和完成判据；共享工程字段按条件启用。 |
| 把工作移交另一会话，或为上下文压缩后继续工作留记录 | [跨 session 交接书模板](跨session交接书模板.md) | 当前有效决定、失效任务、待办、证据、真实路径、未提交状态和授权；提供完整骨架及有条件轻版。 |

执行指令面向“一批动作”，交接书面向“状态与责任接续”。同一份现有任务书若已能承载两者，不必再拆两份或重复填写。只改一处时，保留目标、依据、授权写区、具体差异、交付和完成判据即可；涉及交接时再补关键状态、禁区与失效事项。

模板内已提供必要说明与完整字段，不需要旧发布仓、飞书页面、内部实例或私有 memory 才能填写。执行方的实现裁量受已确认设计、设计系统及工程约束限制；打不开的承重引用必须补足必要内容或明确输入缺口，不让执行方猜。

## 复制与分发

在完整 plugin 中，这个目录位于 `plugins/ai-native-pm/templates/`。把填写后的任务或交接内容保存到使用项目已授权的位置，删除不适用的提示和空表；业务信息不写进 plugin 安装副本。

通用模板只在维护源修改，再生成分发副本；维护源迁移后，旧入口仅指向新的唯一源。下载包或安装目录里的副本不独立维护。本目录不建立新的 skill，也不要求独立 skill 包依赖它；独立 skill 的入口和引用不应必需反链到这里。

以下是完整 plugin 中的**可选**延伸阅读，只有当前任务需要更详细方法时才读；单独复制这三份文件后，没有这些参考也能使用模板：

- [证据与复验](../skills/evidence-check/references/evidence-review.md)：需要细查交付结论的证据范围时使用。
- [术语调整](../skills/backscan/references/terminology.md)：涉及一词多义或批量术语调整时使用。

链接相对本目录，面向生成后的 plugin 布局。发布时核两份模板正文、相对引用及接收副本；文件存在或静态检查通过不等于宿主加载、真实项目消费或运行验收已经完成。
