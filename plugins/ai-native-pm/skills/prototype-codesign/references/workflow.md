# 原型共创状态流

以本轮原型为对象，仅记一个主状态；沿用约定的确认人与授权，不额外增加审批门。

| 当前状态 | 本轮重点 | 转移条件 |
|---|---|---|
| 方案对齐中 | 对齐业务逻辑、动线和范围 | 方案获确认后进入设计对齐中 |
| 设计对齐中 | 对齐表达与交互，保全已定逻辑 | 本轮设计调整获确认后进入待交付 |
| 待交付 | 整理接收方可用的版本与必要索引 | 约定产物已交付，对应副本核验完成后进入已交付 |
| 已交付 | 本轮收口，保留版本与后续问题入口 | 新增改动按影响回到方案对齐中或设计对齐中 |

设计中发生业务改判则回方案；只改布局不重跑方案；沿用已确认设计、无需独立设计对齐的小改可直接进入待交付。交付检查发现问题，按影响回到相关状态；仅整理链接等交付问题留在待交付。提前导出讨论快照是阶段内动作，不自动代表本轮已交付；外部发送仍按具体授权。确认与核验记录各自绑定对象、版本和范围，“已交付”不代表真实服务已验证。
