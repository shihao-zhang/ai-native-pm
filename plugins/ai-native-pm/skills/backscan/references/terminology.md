# 术语调整

单个清楚的改字按任务处理；一词多义、概念更名或批量替换时才用本件。

先列旧词分别指什么：组织对象、操作、处理依据、直接产物或生命周期时点。一词多义时按含义区分，不做全局字符串替换。新名补足影响理解的主语或工作方式即可；例如“自动生成／手动配置”不表示生成后的对象不能配置。

确认保留项：历史归档、原文引述、既有专名、机器接口以及其他责任范围。界面叫法与工程名不同可以合理存在，须明确映射，不把界面替换传播成未经批准的接口变更。

在产品界面、文档和领域概念中检查新名是否撞名或改变承诺；同一语义轴的相关词一起评估，实施可按兼容性和授权分批。无需因一个词变动把所有名词重命名。

需要派单时交付“含义对应、保留项、作用范围、替换及验证方式”，已有表结构能承载就复用。不把内部编号直接变成用户文案。完成后检查相关标题、图例、展开明细、二级文案与当前引用是否一致，历史原件按其保存规则保留。
