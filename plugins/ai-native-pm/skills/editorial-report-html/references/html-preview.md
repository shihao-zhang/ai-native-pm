# 本地 HTML 预览与验收

浏览器验收前读取。验收范围沿用 SKILL.md 第 6 节与设计准则；本文件只规定可移植的操作底线，不依赖特定用户名、安装目录或宿主浏览器。

## 选择可用路径

- 使用当前宿主支持且策略允许的浏览器或原生预览；先读其工具说明。仅把文件打开给人看，不等于代理已验收。
- 文件协议不受支持时，可使用工具明确允许的本地 HTTP 路径。已有合适的项目服务可复用；没有时，自包含单文件 HTML 使用包内预览器。该脚本需要本机 Node.js，无第三方包依赖；未安装时说明前置条件，不擅自安装。

从实际技能目录解析脚本路径，并传入目标 HTML 的绝对路径；不要假定当前工作目录就是技能目录：

```text
node "<技能目录>/scripts/serve_local_html.mjs" "<目标HTML绝对路径>"
```

读取脚本输出的 URL，不猜端口。脚本只监听 `127.0.0.1`、默认自动选空闲端口，只提供指定 HTML，不提供目录列表或邻接文件；允许内联脚本，默认 30 分钟兜底退出。含邻接资源的既有页面需使用范围受限且获准的项目服务，不扩大此脚本的文件暴露范围。

## 服务归属与受阻处理

- 记录本次服务的进程或会话标识、URL、目标文件。验收后主动停止自己创建且不再需要的服务，不靠兜底超时代替清理；复用他人的服务不重启、不终止，不按进程名批量清理。
- 端口绑定因执行权限受限时，说明用途并申请最小必要权限；不把权限错误当作工具不存在。
- 区分协议不支持与明确安全拒绝。安全拒绝时不得通过改绑公网地址、上传私密材料、换浏览器或关闭安全检查绕过。必要时请求用户处理权限或安全提示。
- 允许路径不可用时，可请用户在获准的浏览器中打开目标文件并交接可访问标签页，或提供截图/Appshot。交接后只验证实际可见内容与可执行交互；截图不能证明点击、搜索或打印已通过。仍无法观察时做静态检查并列出待人工复核项，不宣称视觉通过。

## 版本与验收证据

- 并发修改时采用固定快照或协调稳定版本，以内容哈希、commit 或构建标识关联证据；取证后发生修改，重验受影响项。
- 按设计准则检查首屏、密集中段、图表、导航和所用交互；记录文件版本、实际预览通道、视口尺寸、已测项目及结果，保留支持结论的截图。打印能力缺失时明确写“未做打印预览”，不以打印 CSS 检查代替。
- DOM、源码、审计和 HTTP 成功仅证明结构或可达性；真实渲染与交互分别验收。用户截图只覆盖其版本和视口，不外推为全页通过。
- 工具能力变化或当前路径失败时，再用无敏感最小样例复验；不把某次限制写成永久禁令，也不每次重复调研。
